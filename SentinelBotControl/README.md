# SentinelBot Control — راهنمای راه‌اندازی

اپلیکیشن اندروید کنترل ربات شما، متصل به ماژول **HC-05** (بلوتوث کلاسیک SPP).
طراحی: تم تیره با رنگ‌های نئون (سایان/بنفش/قرمز)، مناسب دمو و مسابقه.

## قابلیت‌ها
- اتصال به HC-05 از طریق لیست دستگاه‌های جفت‌شده (Paired)
- کنترل کامل حالت‌های چهره: عادی، خوشحال، غمگین، عصبانی، نگهبان، نجات، دوستانه،
  هشدار خطر، باتری کم، گیر کردن، پاک‌کردن هشدار
- کنترل حرکت: جلو / عقب / چپ / راست / توقف
- حالت خودکار: شروع / توقف
- نمایش رادار زنده (زاویه سروو + فاصله اولتراسونیک) با افکت ردیابی
- بنر وضعیت زنده (STATE) و باکس گزارش کامل داده‌های دریافتی از ربات
- تمام دستورات دقیقاً با کاراکترهای فرمانی کد آردوینو شما هماهنگ است:
  `n h s a g r f d y m k` برای حالت‌ها، `i b j l t` برای حرکت، `u v` برای حالت خودکار.

## نحوه باز کردن پروژه

از آنجا که این پروژه بدون Gradle Wrapper ارسال شده (برای کاهش حجم فایل)، ساده‌ترین
راه باز کردن آن:

1. Android Studio (نسخه Hedgehog به بعد، با Kotlin) را باز کنید.
2. گزینه **Open** را بزنید و پوشه `SentinelBotControl` را انتخاب کنید.
3. اگر Android Studio درخواست ساخت Gradle Wrapper را داد، تأیید کنید (Sync).
4. صبر کنید تا Gradle Sync کامل شود (نیاز به اینترنت برای دانلود کتابخانه‌ها دارد).
5. گوشی اندرویدی خود را با حالت Developer/USB Debugging وصل کنید و Run بزنید.

> نکته: اگر ترجیح می‌دهید، می‌توانید یک پروژه خالی «Empty Views Activity (Kotlin)»
> در Android Studio بسازید و فایل‌های داخل `app/src/main` را جایگزین/اضافه کنید؛
> این کار به‌طور خودکار Gradle Wrapper می‌سازد.

## قبل از اتصال — Pair کردن HC-05

1. از تنظیمات بلوتوث گوشی، HC-05 را جستجو و Pair کنید (پین پیش‌فرض معمولاً `1234` یا `0000`).
2. اپ را باز کنید، دکمه «اتصال» را بزنید، مجوزهای بلوتوث را تأیید کنید.
3. HC-05 را از لیست دستگاه‌های جفت‌شده انتخاب کنید.

## نکات فنی مهم

- HC-05 بلوتوث کلاسیک (SPP) است، نه BLE — به همین دلیل از API استاندارد
  `BluetoothSocket` / RFCOMM با UUID استاندارد SPP استفاده شده، نه Web Bluetooth
  یا BLE GATT.
- اپ خط‌به‌خط داده‌های ورودی را می‌خواند و پیام‌های `RADAR:`، `STATE:`، `FIRE!` و غیره
  را جدا و در بخش‌های مربوطه (رادار، بنر وضعیت، لاگ) نمایش می‌دهد.
- در اندروید 12 به بعد، مجوزهای `BLUETOOTH_CONNECT` و `BLUETOOTH_SCAN` به‌صورت
  Runtime درخواست می‌شوند؛ در نسخه‌های قدیمی‌تر `ACCESS_FINE_LOCATION` لازم است.

## سفارشی‌سازی ظاهر

رنگ‌ها در `app/src/main/res/values/colors.xml` و استایل دکمه‌ها در
`app/src/main/res/values/styles.xml` قابل تغییر هستند. آیکون اپ (وکتور ساده چشم ربات)
در `res/drawable/ic_launcher_foreground.xml` قرار دارد و به‌راحتی قابل جایگزینی با
لوگوی تیم شماست.
